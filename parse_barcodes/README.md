# Parse Biosciences Barcode Data

This folder contains barcode files used for single-cell RNA sequencing experiments in the iNeuron patterning study.

## Experimental Setup

We used **Parse Biosciences WT_mega 96 kit** for the single-cell experiments and **split-pipe v1.04p** to map the data.

## Barcode Files

- **bc1_n192_v4.csv**: Parse Biosciences barcodes corresponding to n192_v4
- **bc2_v1.csv**: Parse Biosciences barcodes corresponding to v1
- **bc3_v1.csv**: Parse Biosciences barcodes corresponding to v1
